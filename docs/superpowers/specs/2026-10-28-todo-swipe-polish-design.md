# Todo 左滑交互优化设计

## 目标

在现有 Expo / React Native Todo 列表中补齐微信式左滑细节：文案随露出程度变灰、卡片与操作块之间出现过渡阴影、操作块展开和收回具有连续动画。保留当前视觉风格、手势阈值、操作宽度和业务逻辑。

## 方案

继续复用 `TodoItem` 中现有的 `reveal` 共享值，不引入 `Swipeable` 或新依赖。所有视觉变化由同一个滑动进度驱动，确保跟手滑动与松手后的补间动画保持一致。

- 文案：标题和时间在前段滑动距离内渐进过渡为弱化颜色；收回时恢复。已完成任务保留现有弱化与删除线样式。
- 阴影：在卡片右边缘增加随 `reveal` 渐显的柔和阴影，完全收回时消失；处理裁切边界，避免阴影被卡片自身裁掉。
- 操作块：保留实时宽度露出，并为操作内容增加轻微的随动位移，使切入切出不只是硬裁切；松手后沿用现有缓出动画展开或收回。

## 范围

仅修改 Todo 列表项的展示与动画代码，必要时补充主题中的过渡色。不修改 Todo 数据、接口、导航、完成／删除操作及其他页面。

## 验证

1. 运行 ESLint 和 TypeScript 类型检查。
2. 在可运行的设备或模拟器中检查慢速左滑、快速左滑、松手展开、右滑收回和点击收回。
3. 检查文案颜色与阴影在动画两端无残留，操作按钮始终可点击，浅色与深色主题均无突兀边界。
